# 人體、服裝與配件

## 人體與換裝結構

同系列角色用相同站姿、正交鏡頭與尺度比對。將腳底、下巴、肩、腰、胯、膝和踝換算到共同高度。頭身比以赤腳腳底到解剖頭頂的高度除以解剖頭高。另量頭寬及身高比例，帽子、髮髻、鞋底各自量外觀輪廓，保留角色的年齡與體型差異。

先建頭、頸、軀幹、骨盆、四肢、手掌與腳，再試穿。核對髖、膝、踝中心線與側影的胸廓、足跟、鞋尖和頭部深度。膝下急折先查相鄰截面中心位移，確認關節走向再修小腿形狀。精修皮膚先用原色、灰模與必要的射線檢查腋下、腿根和髮束縫隙，判斷凹陷、真孔、法線和貼圖殘色。

適合做截面建模時，可在 Blender Python 中使用 [loft.py](../scripts/loft.py)。截面列由下到上，每列為高度、中心 x、中心 y、x 半徑、y 半徑，使用場景單位。傳入物件名、截面列、collection 及 material。可做衣筒、靴、背包和髮束，側壁 UV 位於 V 0.24–0.76，兩個端蓋各有 UV 島。臉、耳廓、蝴蝶結環、開口衣襬按實際結構建模。

換裝保留完整人體，服裝殼、髮型與配件分開。手套下有手、靴下有腳、短褲下有骨盆和腿。各套裝用命名清楚的集合及同一個控制值切換視窗與算圖。按照裁片、內襯、束帶與扣件的穿著層次，給必要的厚度及真實開口。局部檢查離膚距離、寬鬆量、內外層和接合。

## 先放固定端，再做自由端

沿「末端 → 固定件 → 承載件 → 人體」找接點。馬尾根嵌入後腦髮量、蝴蝶結固定在髮束、杯子經掛環連到包帶。用承載表面的射線交點定位，加入接觸厚度，再塑自由端。修懸空時優先挪固定區及相鄰幾圈，保留已核准的髮量和外輪廓。

檢查可見部件整體連回人體，且指定根部接在正確的承載件。馬尾中段碰衣領仍可能懸空。用 [接點驗證](contact-check.md) 檢查封閉部件及嵌入深度。開口布、刻意留縫、磁浮件按設計標準判定。換裝或變形後重查求值網格。

## 裁片與材質

- 側稿中互相遮擋的背包、外套與袖口，個別記錄可見的前後邊界。深色衣物貼背景時保留應存在的布料像素，也保留袖口、腿間的真實負空間。看原色、灰模、射線和內側近照判斷疑似破洞。
- 依裁片對齊領口、側縫、滾邊、口袋、扣件及鞋底。袖筒端面用獨立貼圖與內襯。立體口袋或掛件做好後，清除底布上重複的圖案。皮膚按需要分材質，連續表面保留色調光澤銜接。布面、內襯與扣件維持各自質感。
- 換裝後檢查露膚、頭髮和衣片的殘留投影。隱藏人體查袖口、手套、腰側、褲腳與內層誤留的皮膚。完整服裝驗收用相同角度逐套檢查裸身、預設與替換服裝，並在隱藏人體後查看衣物內側。補查裙下、胯、腋、肩縫與褲管內側等受影響區域。活動中的袖口與下襬接合讀 [動作與穿模](motion-and-clearance.md)。
