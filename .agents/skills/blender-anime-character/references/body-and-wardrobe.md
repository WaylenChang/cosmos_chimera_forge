# 人體、服裝與配件

## 用已完成的模型定頭身比

在中性直立休止姿勢，使用世界座標的垂直高度。記下赤腳腳底、解剖頭頂與下巴最低點，以（頭頂 − 腳底）÷（頭頂 − 下巴）計算。先隱藏頭髮、帽子、鞋及配件。若頭頸共用網格，標出下巴，不可直接取整個物件最低點。

本專案已完成主角的 Blender 基準如下。來源位於 Drive 的 `characters/chr_protagonist_<角色>/03b_blender/chr_protagonist_<角色>_03b_blender.blend`。這三檔取原始網格 `Head` 上下界與 `Body surface` 最低點，使用物件世界變換。表中座標單位為公尺，比例使用未四捨五入的值。

| 角色 | 赤腳腳底 Z | 頭頂 Z | 下巴 Z | 實測頭身比 |
| --- | ---: | ---: | ---: | ---: |
| amemori_sumiha | 0.0150 | 1.5375 | 1.3127 | 6.77 |
| roen | 0.0150 | 1.6187 | 1.3840 | 6.83 |
| yeh_chengxi | 0.0150 | 1.5600 | 1.3353 | 6.87 |

同風格、近似年齡與體型的人形新角色，可用三者中位數 **6.83 頭身**起稿，再依最相近的成品和角色設定定案。例如以 Roen 為比較對象，目標 6.83、赤腳高 181 cm，則解剖頭高約 26.5 cm。兒童、特殊體型或明確指定的比例應另選參照。比較檔改版時重新量測。在製作紀錄中列出比較檔版本、角色目標、成品實測及差異理由。`tools/acg-character/specs/` 中三位主角的 `proportions.heads` 均為生成目標 7.0，與上表的成品量測分欄記錄。

## 人體與換裝結構

同系列角色用相同站姿、正交鏡頭與尺度比對。將腳底、下巴、肩、腰、胯、膝和踝換算到共同高度。另量頭寬及身高比例，帽子、髮髻、鞋底各自量外觀輪廓，保留角色的年齡與體型差異。

先建頭、頸、軀幹、骨盆、四肢、手掌與腳，再試穿。核對髖、膝、踝中心線與側影的胸廓、足跟、鞋尖和頭部深度。膝下急折先查相鄰截面中心位移，確認關節走向再修小腿形狀。精修皮膚先用原色、灰模與必要的射線檢查腋下、腿根和髮束縫隙，判斷凹陷、真孔、法線和貼圖殘色。

### 雙手的五指與掌部接合

左右手逐手驗收。張手時，拇指、食指、中指、無名指與小指各有獨立輪廓；指蹼以上直到指尖均應分離，指縫間不得殘留跨指面或體素重建的薄橋。指根與掌部保留連續皮膚。沿網格從每根指尖追到掌部，並在相鄰指節之間檢查截面；整手同屬一個連通元件，仍可能藏有指間黏連。

卸下手套，從掌心、手背與指尖方向拍近照；逐指彎曲、張指、握拳及拇指對掌，在求值網格檢查指根裂開、掌面破洞、指腹互穿及相鄰指被權重拖動。戴回手套重測指套、開口和袖口。修正合併、重拓樸或權重後重跑相同姿勢。

適合做截面建模時，可在 Blender Python 中使用 [loft.py](../scripts/loft.py)。截面列由下到上，每列為高度、中心 x、中心 y、x 半徑、y 半徑，使用場景單位。傳入物件名、截面列、collection 及 material。可做衣筒、靴、背包和髮束，側壁 UV 位於 V 0.24–0.76，兩個端蓋各有 UV 島。臉、耳廓、蝴蝶結環、開口衣襬按實際結構建模。

換裝保留完整人體，服裝殼、髮型與配件分開。手套下有手、靴下有腳、短褲下有骨盆和腿。各套裝用命名清楚的集合及同一個控制值切換視窗與算圖。按照裁片、內襯、束帶與扣件的穿著層次，給必要的厚度及真實開口。局部檢查離膚距離、寬鬆量、內外層和接合。

### 分件與材質清單

依角色實際穿戴逐項登錄「品項 → Blender 物件 → 附屬件 → 材質 → 固定或變形方式」。上衣、外套、褲／裙、鞋靴、手套、帽子、包包各自有可單獨選取和隱藏的網格物件；需要分別拆換的左右件也分開。集合管理整套顯示。逐件隔離，確認移除時只帶走該品項及其附屬件，人體、頭髮與相鄰衣件仍完整。匯出時以目的端的物件或節點重做拆件檢查。

| 立繪部位 | 造型與固定點 | 材質與近照檢查 |
| --- | --- | --- |
| 口袋、袋蓋、包包 | 做出袋體容積、袋口、翻蓋厚度與縫合邊；查側面凸量與承重帶接點 | 分辨外布、皮革、內襯與扣件；打開或斜看袋口查內外面 |
| 背帶、綁帶、鞋帶 | 沿身體或包體繞行，補厚度、穿扣、搭接與自由端；手臂放下後複查 | 織帶、皮帶、金屬環扣分材質；斜光辨識粗糙布紋、皮面反光與五金高光 |
| 領口、翻領、袖口 | 建出開口、折返、內襯和滾邊；低頭、抬臂時檢查離膚距離 | 區分表布與裡布，從內側確認材質與法線 |
| 吊掛物、徽章、裝飾 | 做出影響輪廓的厚度與背面，掛物經繩、環或釦接回承載件；分清固定端與擺動端 | 依原設計區分布、皮、金屬、玻璃或琺瑯；轉動光源檢查反射、粗糙度與透光 |

立體構造用灰模斜視和側面查輪廓與遮擋；平面印花、刺繡紋理可用貼圖或法線表達。再以相同鏡頭檢查材質，避免立體零件下方重複保留同一件裝飾的投影。

## 先放固定端，再做自由端

沿「末端 → 固定件 → 承載件 → 人體」找接點。馬尾根嵌入後腦髮量、蝴蝶結固定在髮束、杯子經掛環連到包帶。用承載表面的射線交點定位，加入接觸厚度，再塑自由端。修懸空時優先挪固定區及相鄰幾圈，保留已核准的髮量和外輪廓。

檢查可見部件整體連回人體，且指定根部接在正確的承載件。馬尾中段碰衣領仍可能懸空。用 [接點驗證](contact-check.md) 檢查封閉部件及嵌入深度。開口布、刻意留縫、磁浮件按設計標準判定。換裝或變形後重查求值網格。

## 裁片與材質

- 側稿中互相遮擋的背包、外套與袖口，個別記錄可見的前後邊界。深色衣物貼背景時保留應存在的布料像素，也保留袖口、腿間的真實負空間。看原色、灰模、射線和內側近照判斷疑似破洞。
- 依裁片對齊領口、側縫、滾邊、口袋、扣件及鞋底。袖筒端面用獨立貼圖與內襯。立體口袋或掛件做好後，清除底布上重複的圖案。皮膚按需要分材質，連續表面保留色調光澤銜接。布面、內襯與扣件維持各自質感。
- 換裝後檢查露膚、頭髮和衣片的殘留投影。隱藏人體查袖口、手套、腰側、褲腳與內層誤留的皮膚。完整服裝驗收用相同角度逐套檢查裸身、預設與替換服裝，並在隱藏人體後查看衣物內側。補查裙下、胯、腋、肩縫與褲管內側等受影響區域。活動中的袖口與下襬接合讀 [動作與穿模](motion-and-clearance.md)。
