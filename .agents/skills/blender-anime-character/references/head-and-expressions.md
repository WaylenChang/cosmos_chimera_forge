# 頭部精修與形態鍵

用於五官、髮型、髮飾、帽子、皮膚材質，以及說話口型與表情。先保留已核准的正面，再處理側面遮擋。只修鼻子、下巴或嘴部起伏時，從既有眼睛和表情做回歸。

## 1. 讀正側面，先校準輪廓

- 取同角色、同朝向的正側立繪與正交側面圖，選可見近眼的眼心及頦底作錨點。先校正頭部俯仰與轉角，再按眼心至頦底的距離等比縮放、平移重疊眼心。鎖定變換後並排立繪、修前與修後，或疊半透明輪廓。鼻尖、唇緣、耳位、髮際、頭頂和帽沿都是待檢點，逐點挪動或分軸拉伸會掩蓋形狀誤差。雙側依角色自身左右標記；只有一側參考時，標明另一側的推估。
- 正面核對眼型、嘴角與髮際寬度，雙側斜面核對遮擋，正側面核對深度。調帽位時分別開關帽與髮型，記錄帽沿接觸位置。用同姿勢、鏡位、光源及曝光複拍最終匯出模型。
- 正面保留立繪的眼距、眼型、虹膜、眼線、眉形、嘴的圖案和角色表情。側面以可成立的人臉結構安排眼眶、眼瞼、鼻樑、鼻翼、嘴唇與下顎。使用有深度的眼部表面、眶緣與鼻樑遮擋，讓近眼轉側時自然縮短。雙側正側面各確認遠眼被遮擋，斜側面逐步收窄。可用正交射線量可見眼部投影寬度，數值用於同角色回歸。
- 可從已接受的眼部、眉毛、瀏海或嘴部稿擷取各自的圖樣，貼到對應的立體表面。只採樣該部位並處理圖案邊緣，避免把皮膚、眼睛、頸部或配件的殘影留在毛髮或相鄰部件。

### 鼻尖、嘴唇與下巴的側影

- 每人用自己的立繪與已核准表情做同尺度對照。從正側面標出眼睛中心、鼻尖最前點與上唇。鼻樑起於兩眼之間，鼻尖高度應更靠近上唇。高度確認後，沿前後軸微調凸度。若兩版分別過凸、過平，固定鼻尖高度與鼻翼寬度，在兩版之間取值，再看正面鼻下陰影。
- 從鼻底沿人中、上唇、下唇到下巴追蹤連續弧線。臉偏平時，先依立繪補出口鼻周圍到嘴角、臉頰的弧度。自然閉口時雙唇起伏收斂，下唇略退於上唇，下巴平順收在下唇後方。用上唇最前點作垂直參考，核對整段可見唇緣與鄰接皮膚。葉澄汐另驗原有露齒笑的唇形與嘴角。
- 放大正面、左右約 45° 與雙側正側面，用相同鏡位、光源及曝光比對。鼻尖到嘴唇、下唇到下巴的外輪廓與受光面都應平滑，看不到多邊形折線。外輪廓有折角時檢查局部面密度與跨越唇周的長三角面。輪廓已順但仍有黑線或鼻下陰影過重時，以灰模、轉光和無光照材質分辨法線、頂點色或貼圖殘影。保留自然唇縫、唇色與 UV；若重建拓撲，在所有口型核對接縫，再重算法線並驗證匯出模型。

### 耳廓與頦底的側影

- 比對耳高與耳屏位置。依本組立繪，耳廓開口朝角色左右、略偏前。從正面、兩側斜面及正側面檢查耳輪遮擋與耳甲腔深度。負例包括正面看到整個耳窩、側面只剩薄片，或單靠縮耳掩蓋朝向錯誤。實際前傾量依各角立繪判定。
- 從下巴最低點沿底面往後追到下顎與頸部，在兩側輪廓與斜下方檢查走勢。立繪為平順弧線時，第二個下墜低點、鋸齒、突出的鉤形或轉光後出現的折痕都要回查。先以灰模剪影修外形，再檢查材質與法線，並回驗開口及閉口。

### 眉眼貼面與臉部條痕

- 用原立繪標出各眼的內外眼角、上瞼弧與眉毛走向。以同鏡位拍正面與左右約 55–60° 的材質、灰模；轉動光源分辨紋理邊界、相交面與法線折痕。條痕沿網格重複時先查重疊殼、面密度及平滑法線，再調膚色。
- 在眉弓下做漸寬的凹面，上瞼順眼球曲率包覆，中央有厚度，向兩端眼角收薄。依每位角色的眼裂與眉距決定深度及轉折。眉毛沿修後的皮表貼合，檢查表情形變時眉尾與髮際。
- 保留眼型時鎖定正面投影、眼色與虹膜圖樣。固定曝光與鏡位，用無光照圖比對左右虹膜可見範圍，抽驗睜眼、半閉及全閉。從兩側斜角看近眼上緣遮擋、遠眼收窄與閉眼漏色。獨立眼球可用物件遮罩量眼瞼外的可見像素；若全閉仍有細縫，沿閉眼弧線微調眼球與眼瞼的相對位置，並重驗半閉時仍看得見虹膜。
- 若 Blender 中有膚色、GLB 卻泛灰，重匯入後分別檢查頂點色、基色與自發光。glTF 的自發光係數無法直接讀取頂點色；檢查匯出器是否將連線轉成固定白光，並在同一光源下對照臉、耳及頸部。
- 短捲髮先依原稿劃分髮流，再調整每束根部、彎轉方向與疏密；把髮際及鬢角接到髮底，從頭頂與後斜面檢查重複球形輪廓。

## 2. 分離膚色、光照與配件材質

- 用含貼圖、灰模和改變光向的近照辨別下巴黑線、髮際、耳下、頸部和其他露膚區的問題。檢查全身皮膚的 Base Color 輸入，包含換裝後會露出的區域。膚色可含色素變化與腮紅，投影、遮蔽、高光由幾何與打光決定。原圖投影若被烘進膚色，修來源貼圖或材質，重查頸、軀幹和四肢的分區色調銜接。
- 後髮下緣沿立繪補錯落的收尖髮束，髮根先接到後腦髮量，再塑髮尾。從後斜、上方和仰視檢查根部、尖端與脖子／衣領的間隙。補髮時確認髮夾、馬尾、蝴蝶結、帽沿的位置和前版識別特徵。
- 把髮絲、布帶、金屬髮夾、帽布、帽帶及帽釦當作不同表面，對照立繪的色相、滾邊、透光和反射。用斜光看粗糙度差異，補特寫核對側面、帽底、背面及邊緣。配件固定端看 [接點驗證](contact-check.md)。

### 髮型分件與材質驗收

頭髮獨立於頭皮、臉、帽子與髮飾。依髮型建立可辨識、可單獨選取的物件，例如髮底、瀏海、側髮、後髮與馬尾；短髮依實際髮量與剃側區分組。會獨立擺動或拆換的髮束保留獨立組件。髮圈、髮夾和帽緣各自歸入配件，記下承載它們的髮束。

毛髮使用專用材質，依立繪校準髮根、髮尾色階與高光方向；依造型採賽璐璐高光或沿髮流的各向異性反射。金屬夾、布帶與頭皮各用相應材質。分別隱藏帽子、髮飾、髮型，從正側背與頭頂檢查髮根接合、頭皮完整性、髮際殘影，再用斜光檢查髮束和配件的反光差異。重新戴帽、轉頭與低頭，確認固定端仍貼合。

### 髮束側弧與角色辨識特徵

- 依立繪分開髮底外輪廓、突出的小撮及飾件。在既有髮量內沿根、中段、尖端塑形；正側面看瀏海應自額頭拱出再收尖，轉到斜側仍有厚度。負例包括側看像平板、根部懸空、中段硬折，以及整頂加厚來容納新髮束。光滑法線無法修正剪影折角。對照立繪髮色並轉光檢查髮根與髮底銜接。
- **雨森澄羽**以髮底本身的圓頂校準高度，小撮翹髮另外判讀。把翹髮頂點當整頂高度會做得過高，整頂一起壓低又會削平冠部。
- **洛恩**在既定高度調整鼻尖前後位置並回驗鼻下陰影；從側面與後斜面辨認各撮髮尾上翹的幅度和方向，保留髮根走向。
- **葉澄汐**依側影補出口鼻至臉頰的弧度，回驗原有笑容和下唇略退的位置。馬尾從共同束點自然分叉為長短、捲向各異的髮撮，核對束髮蝴蝶結、帽沿、瀏海與頭皮的接觸。
- **雷歐**在同一光照下與三主角比較眼、皮膚、布、皮革及金屬的反光層次，同時保留自身金色虹膜與深膚色。用立繪眼心至頦底的尺度檢查短髮頂高、冠部圓弧和剃側露出區。厚重髮蓋、削平的頂部，以及刻髮被側捲遮住都是負例。依正側立繪確認刻紋所在側、條數、間隔、走向及收尖；在材質模式和實際匯出檔的側面、斜面與正常觀看尺寸複查。

## 3. 中性臉穩定後做可編輯表情

- 先鎖定中性臉及已接受的眼睛，再做需求指定的口型與表情。一般說話可用 A、I、U、E、O 及 M／B／P 合唇。日系 ACG 表情可由微笑、驚訝、生氣、難過、眨眼與左右單眼眨眼起步，幅度以角色立繪為準。
- 用同一個主控制組織 Blender 形態鍵，同步眼瞼、眼球、眉毛、唇緣、下顎、口腔、牙齒和舌頭等受影響部件。基礎姿勢的表情權重歸零。口型只動該動的部位，眨眼支援張口時使用。允許混合的控制用中間權重和極值測一遍，驗嘴角、合唇、眼裂、牙齒穿唇、眉眼與瀏海遮擋。
- **閉口與對話的臉頰。** 以同角色放鬆時的雙頰作基準。自然閉口、M／B／P 合唇與一般對話都應維持飽滿的臉頰弧度。一般發 O 音可收圓唇緣；只有刻意嘟嘴或誇張 O 形才允許嘴角附近輕微內收。從寬笑轉閉口時，隨嘴角回收重塑周圍皮面，避免原笑紋的凹槽或陰影留在臉頰中央。
- 固定鏡位檢查中性、閉口、各母音與原有笑容，再播放連續對話。抽看 I → 合唇、A → O、合唇 → A 的 25%、50%、75% 混合幀，從正面、左右斜面與側面確認雙頰平順、唇緣接合、眼型及表情辨識度。遇到疑似凹陷，以同角色同鏡位比較嘴角外側至雙頰的皮面深度，只採命中皮膚的點，再核對正常材質畫面。交付 GLB 或 LOD 時，在各交付版本重驗。
- 檢查各口型與表情的正面、斜側及易露餡的正側面或仰視。若輸出 GLB，核對形態鍵名稱、零預設與相連部件的形變。身體動作與表情獨立控制時，確認既有片段不以空白或固定權重覆寫表情。Blender driver 由 Blender 求值，在目標端實測同名 morph target 的同步。
