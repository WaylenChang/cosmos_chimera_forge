# 四格動作 GIF 預覽

在專案根目錄執行。需要 Blender 4.4 以上與安裝 Pillow 10.1 以上的 Python。工具會找 `BLENDER`、PATH 或 Windows 的標準安裝位置，可用 `--blender` 指定執行檔。

```powershell
python tools/acg-character/character_motion_gif.py "<最終角色.glb>" --output "<交付目錄>/<角色ID>_motion.gif"
```

優先使用含動畫的最終 GLB，只有 .blend 或動畫只保存在 .blend 時可直接傳入該檔。來源使用單一角色及指定套裝的場景。相機預設從角色正面（Blender 的 −Y）偏轉 25°，朝向不同時用 `--yaw` 調整。

四格由左上到右下依序播放慢走／奔跑、蹲下／跳躍、攻擊／格擋、翻滾／倒地。第一階段各格播放前一個動作，第二階段播放後一個動作，再循環。各片段按來源速度取樣，同階段先播完的格子停在最後一幀。工具先保留全部優先動作，缺項以尚未選用的現有動作補上，片段不足八個時再重用。畫面標示實際片段名稱，橙色文字表示替補。模型完全沒有可綁定的片段時，工具會回報錯誤。

開啟 GIF 檢查四格的全身取景、實際片段標籤、兩個播放階段與循環。附上 GIF 連結，列出替補片段或無法產出的原因。若來源 .blend 依賴 NLA 混合、條帶變速或自訂腳本，優先使用已烘焙的 GLB。

## 多角色同動作比較

需要比較步態、姿態幅度或表演差異時，用各角色最終遊戲檔做成同畫面並排的循環 GIF。每欄固定一位角色，每次播放同一種動作；標出角色與實際功能，例如同一輪中標清「攻擊」與「進攻號令」。採相同視角、可比的全身景別與來源播放速度，每段同時起播，較短的片段可停在末幀等其他角色播完。從既有四格預覽重組時，依每位角色各片段的實際幀數找切點。重開成品核對段落切換、幀延時與循環；要判讀肩肘或裝備間隙時，另附具體問題幀的正側面修前／修後對照。
