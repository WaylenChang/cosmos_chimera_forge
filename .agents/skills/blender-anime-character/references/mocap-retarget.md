# 四角色動捕重定向與驗收

## 先建立修前基準，再調骨架

- 從角色實際載入的 Blender、GLB、遊戲動作對照表與前一個已修版本建立基準。逐角列出動作 ID、現用來源、動捕候選與播放入口，含別名、預設片段、NLA 和仍會觸發的舊動作。展示姿勢另列。保留可還原的修前檔與動畫。
- 打開每位角色的 `角色.prompt.md` 正視圖段落，將每個可見特徵對應到正視參考、模型部件、材質及能判讀的視角。用相同姿勢和光照把模型與正視圖並排；局部過小或被遮住時加近照、斜視或內側視角。看不清楚的項目留作待查，補拍後才能判定。
- 用雨森作本組比例基準。在相同綁定姿勢、赤腳且排除頭髮、帽子與耳機的條件下，量身高、頸根至頭底、兩肩關節間距、上臂、前臂、掌長及上下腿長，記錄長度與身高比。先按個別身高和體型校正骨架與素體，再更新權重、衣袖、袖口、手套及掛點。對照肩臂肌肉體積、掌寬、指長和關節彎折處；重穿整套確認輪廓。
- 洛恩的頸根與肩點從人體地標取得，暫藏頸掛耳機再量；若先前用了耳罩邊緣，重算頸長、肩寬和臂長。縮短頸部後完整重建或調位頭帶與兩側耳罩。洛恩、雷歐優先查肩窄、臂短與跑姿縮成一團；葉的四肢依雨森比例略收，仍保留各自體型。用綁定姿勢的量值區分比例偏差與運動中肩肘內夾。

## 把來源動作套到每一副目標骨架

1. 取得使用者指定的[人形骨架與動捕庫](https://drive.google.com/drive/folders/1tHwde_PWFl3PARxx5Kz5zm6JQYG2KgqJ)片段，記下來源檔、take、軸向、單位、幀率和根位移。核對來源與目標休止姿勢、左右側、骨骼對應及局部旋轉軸；在調整後的四副骨架分別重定向、烘焙並播放。記錄沿用、重定向、補作和缺少來源的片段。
2. 初選時，每位角色各自比較「上一個已修版本」與「實際重定向候選」，依支撐、頭頸、擺臂、手腳方向和穿模選較自然者。本組已選定四人採用動捕版；後續沿用核准結果，雷歐所有仍在使用的對應動作走與其餘三人相同的動捕來源與節奏，再做體型、裝備避讓。從正常播放入口逐項觸發，核對實際播放曲線與片段來源，抓出同名或別名指向舊版的情形。
3. **跑步的頭頸與肩肘。** 側面看頭頸延續軀幹前傾，略抬頭使視線向前。正面看肩線、肘距及前臂走向，特別查雷歐的前臂外張。以胸廓局部向上軸逐幀量左右肩關節相對鎖骨內端的高度，與本角綁定姿勢及自然擺動比較。若沉肩，先查鎖骨映射、休止姿勢差和肱骨補償，再複看整個步態週期的擺臂與衣肩。
4. **拳形與腳步。** 四人跑步可實握或虛握，拳眼大致向上且與前臂垂直。以掌側和側面近照檢查拇指根、關節屈曲、拇指搭在指外的位置、掌指連續及手套穿插。洛恩、雷歐若像踢到自己，逐幀對照左右髖膝踝、腳尖朝向、鞋底落點及擺動腳與支撐腿的最小間隙，分辨步寬、足部映射或鞋形造成的問題。
5. **跳躍與待機。** 原地跳逐幀量根骨與骨盆的水平軌跡，同看起跳、最高點和落點，找出途中左右偏移及落地漂移；保留垂直起伏。連播多次待機並放大固定腳、骨盆與肩，檢查相鄰幀與循環接縫，保留平順呼吸；依[顫抖與循環診斷](motion-and-clearance.md)追到曲線或播放端。全套其餘動作也要檢查身軀與四肢的接觸、支撐及極端姿勢。

## 將軟組織、布料和硬裝備分開處理

依各角色可見的肌肉、皮下軟組織與服裝覆蓋區，標出受力端與可動區。例如上臂、胸腹、大腿在落地、急停或轉身時可短暫滯後回穩；待機則依呼吸與姿勢微動。依體型、組織與衣物支撐調整幅度，從每個動作的加速、制動、回穩及循環接縫複查。按[動作與穿模驗收](motion-and-clearance.md)檢查網格與固定端。

| 雷歐檢查部位 | 動態與接觸判讀 |
| --- | --- |
| 風衣下襬 | 各裁片在重力下自然垂落。轉身、蹲下、倒地和起身要查內外層布對布、布對腿及布對裝備；容許軟布貼合、滑動、分離，維持布長與摺疊，修掉互穿、彈開及跳幀。 |
| 腰包 | 分別看皮帶或腿帶、固定耳、包體與翻蓋。掛點貼住原處，包體隨負重小幅擺動；查大腿、手臂、外套及鄰包。 |
| 信號旗 | 把旗桿及端頭視為硬件，旗布自由端保有延遲與阻尼；檢查布、桿、身體與附近裝備在擺回時的交錯。 |
| 三腳架 | 保持桿件、腳端與束環相對位置，從實際固定點轉動。倒地、翻滾和起身逐幀量掛點相對骨盆的位移與轉角；播放檢查是否瞬移、折彎或飄離腰帶。 |

## 回到立繪與正式輸出驗收

- 雨森以近照分別辨認細辮、三角髮夾、紅金耳飾。洛恩加拍看得到帽內側的角度查鮮橘內襯。雷歐依正視圖核對頸掛耳機的前後、左右與耳罩朝向。雷歐服裝以正面可見服裝區域量炭灰／古銅／電藍的面積占比，目標 60／30／10；記錄遮罩範圍、色分類方式與實測值，排除背景、皮膚和頭髮。以材質遮罩輔助區分陰影，修後用同一口徑重測並與立繪並排。其餘正視圖特徵依各角清單逐項核對。
- 在實際交付檔按原幀率逐幀檢查全部在用動作。記錄碰撞部件對、幀號、檢測範圍及有意接觸的縫線或掛點，修掉發現的穿模，再複查肢體和鄰件有無新增碰撞。另量掛點單幀位移、轉角及循環首尾差，播放檢查材質重量與回擺。數值門檻依角色尺度、動作及材質判定。
- 每個受檢動作輸出同步的「修前正面／修前側面、修後正面／修後側面」動畫，標明角色、版本與片段；鎖定鏡頭、取景、速度和起始相位。另附跑步肩頸、前臂、拳形或配件疑點的近照，展示定格用靜圖。跨角色比較用[多角色同動作比較](motion-preview.md#多角色同動作比較)。把動畫與逐動作結果連在一起，讓讀者能從問題幀回看整段。
- 重開可編輯 Blender 檔，再匯入最終 GLB，核對動作清單、肩線、掛點、權重、材質與實際播放。正式檔有對應 LOD 或鏡像時一併核對；通過後更新授權的交付目錄，保留修前基準與可查的版本對應。
