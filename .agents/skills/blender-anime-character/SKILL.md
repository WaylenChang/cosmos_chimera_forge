# 從立繪到可編輯的 Blender 角色

## 每一階段的迭代與美術檢查表

每位角色開工時建立一張可持續更新的檢查表，列出本次適用的每個流程：設定對圖、比例與素體、頭臉髮型、服裝與材質、綁定與動作、多角度對圖、重開檔及匯出播放。每列填寫「驗收條件｜版本與畫面或幀號｜觀察到的差異｜本輪修改｜同條件複驗結果｜狀態」。多人共用同一格式，各自留存判定；未適用項註明原因。

每一階段都以「檢查 → 找出差異 → 修改來源 → 同條件複驗」反覆迭代。已有證據滿足條件即可往下走；失敗項保留修前、修後與下一輪要驗證的成因。下游修改影響先前結論時重開該列。分別標記通過、待修、待確認；交付頁顯示尚未關閉的項目。動畫能播放與美術達標分列驗收。

角色美術品質以《薩爾達無雙》為目標，造型與配色依本角色設定。用同一姿勢、鏡頭、曝光及顯示尺寸比較：
- **戰鬥全身景別**：縮至實際遊戲尺寸，檢查頭髮、外套與標誌性裝備的輪廓，以及動作轉折時的肢體辨識度。
- **對話近景**：對照正面、斜側與側面，檢查眼瞼包覆、鼻唇下巴的側影、髮束層次及臉部明暗；再看眨眼、口型切換是否破形。
- **材質與運動**：固定燈光比較皮膚、布、金屬與半透明件的高光和色塊；用相同問題幀核對接點、穿出及回擺。檢查表記錄具體可見差異及圖像證據。缺少可比畫面時，美術品質標為待確認。

### 人體量感、固有色與頭髮接合

- 依角色立繪定位肩峰、胸廓、腰臀、肘、膝與踝，再比較胸背厚度、上臂、前臂、大腿及小腿的截面。把衣袖、肩甲、披風的外輪廓與人體地標分開量測。依角色個別補足三角肌、胸背、臀腿及小腿的體積，保留關節收束、左右差異與原動作。記錄修前、修後尺寸及同鏡頭疊圖，並回看素體、穿衣與屈肢狀態。
- 檢查皮膚與其他材質的 Base Color。用無光照底色、均勻環境光及相反方向主光交叉比對立繪。辨識鼻側、眼下、顴骨、下巴、頸部與髮絲的投影或反光，消除固定在貼圖上的方向性明暗；保留角色膚色、唇色、雀斑、鬍色及服飾紋樣。記錄被調整及受保護的區域。
- 在正面、兩側、頂視、背面與後方斜俯視，用同焦距、姿勢及曝光對照修前、修後。檢查頭頂拱度、髮流旋向、後腦體積及髮片與髮束的接縫；髮根需貼合，粗細、顏色及高光方向需連續。修改頭頂與後腦後，重驗正面髮際、眼眉可見度、側影與頭飾位置。

- 肩臂看起來過寬時，先比較綁定姿勢與垂臂待機的左右上臂骨中心距，再量同高度上臂內緣到胸側的空隙。分別檢查鎖骨、上臂的動畫平移、胸廓側寬及衣物厚度。按角色提示詞保留寬肩或修長的個別設定。
- 在去衣灰模上用正面和斜側光確認胸大肌由胸骨、鎖骨向上臂收束，側胸銜接前鋸肌與腹外斜肌，腹直肌圍繞白線形成體積。依身材和皮下組織厚度控制起伏；身高、圍度與體型形容詞須標明來源。
- 捲髮底層只需遮住頭皮，側面輪廓留給分層、扭轉、尖端回鉤的外髮束。兩側都要看見前、中、後層次，再檢查頭飾與髮根。單側辮子先標出角色左右、前後與髮根到辮尾的路徑，並用正側背三視圖核對。

- 胸口出現深線時，用素體灰模在綁定姿勢與垂臂姿勢重現，沿線檢查網格是否連通、截面深度與骨骼權重過渡。修後從正面及斜面確認胸骨兩側、胸肌下緣與肩前皺襞可辨，腋窩有自然凹度，接面沒有斷線或點狀摺痕。
- 短捲髮另存單獨底髮與完整髮型的同側面圖。用底髮到頭皮的實際距離確認厚度，依立繪檢查外髮束的起伏、鬢角長短、側向翹起的髮尾與額前分線。

- 評估肩帶、腰髖與頭頸之前，先核對鎖骨內端、肩胛盂與肱骨頭、髖臼與股骨頭，以及上頸椎與枕骨的位置。用垂臂、抬臂、跨步及轉頭的同幀素體，檢查變形能否沿相鄰部位連續傳遞。自訂姿勢和遊戲內烘焙動作分別驗證。
- 依立繪逐件記錄緊身、合身或寬鬆，並標出受力點與自由衣緣。外套、背心、寬褲與披肩以可單獨顯示的裁片製作，檢查襟口、袖口、褲管和內搭在抬臂與跨步時的空間；保留實際需貼身的飛行衣或潛水衣。交付穿著、移除主要外層與外層單獨展示三張同鏡位圖。

## 先找這次要改的部位

- **待機低頭、前傾或鞋高不符立繪**。依[待機視線、承重與接地](references/motion-and-clearance.md#待機視線承重與接地)診斷整段循環；靴筒、外底與褲腳的連動見[門襟與鞋靴比例](references/body-and-wardrobe.md#門襟與鞋靴比例)。
- **服裝分層後細節流失或動作中穿模**。先核對各衣件的立體結構和貼圖歸屬，再依[服裝問題幀與動作切換](references/motion-and-clearance.md#服裝問題幀與動作切換)檢查局部和全身。

- **頭部、斜側眉眼、材質或表情**。臉型、側面眼睛、鼻尖高度與凸度、鼻唇至下巴的平滑側影、閉口與對話時的臉頰、後髮、髮飾及帽子，讀 [頭部精修與形態鍵](references/head-and-expressions.md)。
- **新建人體或可換裝服裝**。比例、皮膚、裁片、鞋襪、懸掛件及接點，讀 [人體、服裝與配件](references/body-and-wardrobe.md)。需要判定髮根或扣件接觸時再讀 [接點驗證](references/contact-check.md)。
- **動捕替換、四角色比例或裝備動態。** 從[四角色動捕重定向與驗收](references/mocap-retarget.md)開始，依序對齊人體地標、實際重定向、核對播放來源，再用正側面同步動畫驗收。該流程列有雨森、洛恩、葉、雷歐的正視圖特徵與動作複查要求。
- **遊戲角色動作**。製作整套動作、區分角色表演，或修正畏縮與開合過大時，依[逐段選參考與姿態幅度校正](references/motion-and-clearance.md#遊戲動作的逐段參考與角色表演)處理。多角色同動作比較見[並排 GIF](references/motion-preview.md#多角色同動作比較)。
- **骨架、動畫或穿模**。處理顫抖、循環、四肢交疊及衣物變形時，讀 [動作與穿模驗收](references/motion-and-clearance.md)。多角色先以代表角色驗證臉部光影與次級動態，再逐角套用。全動作穿模任務依該章的逐幀流程，比對完整 GLB 與遊戲 LOD，並據驗收結果決定是否更新 3D 模型目錄。
- **只驗收**。重開現行檔案，做指定對照並指出差異。精修時沿用相同鏡頭及檢查條件，補拍受影響區域。

## 新建角色的處理順序

1. **先讀正面圖 prompt，再對照立繪。** 開啟該角色實際使用的 `*.prompt.md`，讀出正面圖（正視圖）prompt，與角色立繪及正視參考逐項對照。把外形、髮型、服裝、配件、配色、材質、圖案及左右位置等明列細節列成建模清單，註明每項要落在哪個網格、材質或貼圖。文字有寫而立繪遮住的細節仍須實作；兩者矛盾時記下差異，依已確認的角色設定處理。
2. **定比例。** 從同系列已完成模型選比較角色，依[人體比例與分件](references/body-and-wardrobe.md)量出頭身比，寫下本角色的數值目標及選擇理由。
3. **建完整人體。** 先驗赤腳素體比例與左右手五指，再試穿。保留脫下手套、鞋靴後仍可編輯與擺姿的手腳。
4. **拆件再做細節。** 依立繪列出實際穿戴件，逐件建立物件，完成裁片、附屬件、固定端與材質。依[頭部與髮型](references/head-and-expressions.md)獨立建立髮型，再試戴帽飾。
5. **綁定並驗收。** 依[動作與穿模驗收](references/motion-and-clearance.md)逐件確認固定端、重力與運動慣性，再測手指、穿戴件、髮束及吊掛物。分別檢查素體、單件與整套的灰模和材質，量回成品頭身比，再進入下方的多角度與重開檔驗收。
6. **逐項對圖驗收。** 將成品正面渲染與立繪、正視參考並排，照建模清單逐項指出實作位置與可辨識的畫面。細小或被遮擋的特徵補拍近照、側面或內側；漏做、做反或配色不符就修正並重拍。仍無法判定的項目標為待確認。

## 建立基準、精修與交付驗收

1. **鎖定來源與比較基準。** 找目前採用的 .blend、角色立繪、正側背轉面和實際使用的匯出檔。先確認人形、材質、骨架與動作由哪個檔案或生成腳本管理。工作區有 tools/acg-character/ 時，先找已存在的角色生成、表情和動作流程。有可重跑的生成器時修改來源並重建，手工製作的部分保留可編輯來源。精修用上版做基準，記下使用者指定要保留的眼型、圖案、動作、套裝等。若要求盲建，完成並留存初稿後才開現版。轉面沒畫到的深度、背向細節及光澤屬於推估。
2. **用少量固定鏡頭找成因。** 先拍正面、雙側面、問題側斜視、相應上視或下視及灰模。用固定正交尺度、姿勢和部件可見性比對修前／修後，頭部依[立繪對位與側影驗收](references/head-and-expressions.md#1-讀正側面先校準輪廓)鎖定眼心與頦底，核對左右方向、耳廓開口、頦底至頸部及瀏海側弧。只有材質出現的瑕疵優先查貼圖與材質，灰模也出現的瑕疵再查網格、法線和變形。動作先抽問題片段及峰值前後幀，在 Blender 與目的端比較。只在需要判斷成因或選方案時增加算圖。多角色共用流程時，臉部與動態各選代表角色。固定光源、曝光、姿勢，比對正面、斜側與遊戲全身景別的眉眼及下顎；用同一轉折動作量髮束、垂袖及吊物末端相對固定端的回擺。留存修前修後圖和逐幀量測，再逐角套用。比較 LOD 或合批時保留可編輯來源、表情及換裝，量測目的端幀時間及輪廓。
3. **按依賴順序修。** 先定輪廓、遮擋、固定端和變形，再補材質、髮絲、縫線等細節。既有角色只動確認有問題的部位和受影響的匯出。每輪用同一快照檢查使用者的保留要求。少量視角已顯示同一缺陷連續兩輪未改善，就回查來源、材質或網格，針對疑點做更小的測試。
4. **候選版穩定後做完整驗收。** 頭部、皮膚、服裝或接合的多角度驗收，每位角色至少覆蓋 8 個水平角與 8 個俯仰角，含上下視。要求角度矩陣或既有規格要求交叉覆蓋時，拍完整矩陣。逐一看與改動有關的畫面，保留立繪、修前與修後對照。涉及服裝、表情或動作時按專項測試附著和變形，記下抽樣範圍。局部改動尚在迭代時，用步驟 2 的固定鏡頭做回歸，完整覆蓋留到定稿。

## 局部修改後的全身複查

- 在修改前保存同鏡位、同動作影格的穿衣與去衣灰模。修改後複查正、側、背剪影，從臉頸、肩腋、胸腹、手臂到骨盆、大腿、膝、小腿與足部逐區勾選。以抬臂、跨步、跑動和轉身確認遠端部位。骨架或權重有變動時，另比較修改範圍外的靜止頂點、權重與各動作播放取樣。
- 依立繪畫出皮膚、鞋口與褲口的實際邊界。逐件定義內搭、背心、外套及左右靴的版型和材質歸屬。單獨顯示各件，檢查袖窿、衣襟、領口、內外鬆量和鞋筒全周；取色或投影前遮除皮膚和其他衣層。
- 用正式版與低細節版重驗網格、蒙皮及貼圖歸屬；保留局部特寫、全身前後對照、動作與逐角檢查表。有異常就回到對應步驟修正並重驗。

## 交付

將可編輯 .blend 與要求的匯出先寫入暫存區，另開 Blender 複查已打包貼圖、拓樸、骨架、套裝和動畫等受影響的資料。有 GLB 或其他交付格式時，重匯入該檔，並測實際載入器的功能與播放。比對過關後才更新現用交付檔，保留可恢復的前版。交付檔案、對照圖、有意義的量測及仍可見的差異。把確認過的缺陷留下可重跑的檢查。

每次完成角色建模或模型精修，依[四格動作 GIF 預覽](references/motion-preview.md)用最終交付候選檔為每位角色產出並檢查一張循環 GIF。交付時附 GIF 連結及替補片段。若模型沒有可播放片段，仍執行工具確認，並記下缺少動畫而無法產出的原因。
