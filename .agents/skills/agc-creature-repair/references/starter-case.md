# 御三家修復案例

來源為 Codex 對話「精修宙獸外觀與材質」。日線白鷺、月線灰狼及星線飛馬各有幼年、少年、成年與超載四個型態。原案依序進行外觀材質修整、原型與動作校對、偏差零件替換。新案件先確認原型差異與零件處置，再精修材質，可減少在待替換的幾何上重工。

| 部位與症狀 | 處理與複查 |
|---|---|
| 白鷺翼根像厚板，幼鷺短喙藏在頭部 | 沿翼面重建薄覆羽與收尖飛羽，重建上下喙並分別跟隨頭、下顎。用正側面與斜上方確認短喙和羽列。步行收翼，飛行收頸、雙腿後伸。 |
| 灰狼尾巴像分節硬片，頸背交界突兀 | 重塑口鼻、趾墊、爪尖和分束尾毛。幼狼毛束較短，頰毛向後、胸毛向下、背毛貼身。以步行、小跑、疾馳觀察尾根到尾尖的延遲和足部輪廓。 |
| 飛馬鬃尾像直帶，翼根與肩接合生硬 | 沿額頂與頸脊重塑額鬃、頸鬃和尾鬃，翼根覆羽採薄截面。讓尾根接入帶骨盆權重的臀部表面，再跑步複查原有縫隙。地面跑步收翼，另播振翼片段。 |
| 三家族原始 GLB 貼圖索引超出範圍 | 以各家族原色彩、法線及材質貼圖恢復工作副本連結，核對圖集與 UV。重建眼睛時分清虹膜、瞳孔與高光。白鷺象牙白羽面與金色鏡框以粗糙度、金屬反射和色彩區分。 |

## 取樣與複查

- 讓 0° 對齊模型正前，每 45° 一個方位。俯仰採 +75°、+50°、+30°、+10°、0°、−20°、−45°、−75°，每個俯仰保留全部 8 個方位。以俯仰排成列、方位排成欄，格內標角度，跨階段另做總覽。
- 循環可等距取 `0/8` 至 `7/8` 相位，另確認接觸、最大伸展與首尾銜接。看尾根等局部時加固定尺度近景。測試根節點突然位移或模型消失時，用固定世界座標攝影機，避免自動取景跟著資產移動。
- 原案 12 個模型共製作 768 個靜態視角，以實際 GLB 播放 50 段代表動作，留下 400 個取樣，並重開 12 份 Blender 檔。原案紀錄仍列有全動畫逐幀穿插、足底滑移與遊戲內動畫混合待驗。

## 專案內的可用素材

- `docs/STARTER_3D_REDESIGN_V3.md`、`anatomy-profiles.js` 和 `tools/anatomy_starters_v3.py` 可用於查宙獸規格、骨架及既有製作流程。實際來源與型態立繪依當次資產定位。
- 歷史工作區若仍保有 `Art/_incoming/starters_anatomy/原型審查.md` 與 `Art/_incoming/starters_rebuilt/verification.json`，可依部位、GLB 雜湊與取樣數追查原案。執行本 Skill 可用當次資產與既有檢視工具完成。
