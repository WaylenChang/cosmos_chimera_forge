# 奇幻生物修復

先逐部位對照原型，再檢查全身與動作。以原創立繪的辨識度、部位連續性、材質層次和可讀的動態輪廓衡量完成度。

## 1. 確立範圍與基準

- 從資產 ID、圖鑑或檔案定位家族、型態、立繪、可編輯來源或生成器、GLB、貼圖、骨架及動作。一次釐清會影響施工的缺項。範圍已明確時直接進行。
- 該型態的正式立繪與設計規格約束角色辨識和幻想特徵。原型物種提供解剖、毛羽生長、支撐與運動的依據。混種依部位指定對應原型，並標記因遮蔽或缺少轉面而須推定的構造。
- 用工作副本保留原資產與可重現來源。原檔無法載入時，先查貼圖／材質索引、UV 圖集與資源連結。以該資產的已知正確貼圖恢復可比較的基準，記錄修復項目。
- 宙獸設計疑義讀 [agc-creature-design](../agc-creature-design/SKILL.md) 的相關規格。通用的 Blender 資產、骨架或匯出細節可查可用的 `image-to-3d`。

## 2. 逐部位決定保留、修整或重建

- 對照每個型態的主輪廓與構造。檢查實際存在的毛髮、羽翼、犄角、喙／牙、爪、鱗片、鰭、尾、觸鬚、眼睛、圖騰與元素效果。記下部位、參照、偏差、處置與驗收視角或動作。比較附著點、走向、截面、比例、分節、材質及受力後的形變。
- 輪廓、附著與運動合理的部位可保留。局部偏差用改形、重配權重、UV 或材質修正。構造偏差大時，沿正確解剖地標與骨鏈直接重建該部位，移除衝突的舊幾何，保留已驗收的相鄰構造與可用骨架。
- 依構造做形。覆羽薄而搭疊，飛羽收尖且可辨羽列，毛束循生長方向，鬃毛從生長線垂落，鱗片沿軀體成列。剛性部位以對應骨或固定座控制，關節交界用連續表面或合適的蒙皮過渡。
- 先定附著與形變，在休止與極限姿勢檢查翼根、肩頸、尾根、足爪等交界，再修 UV、法線、色彩、粗糙度、金屬度、透明或發光。材料分界跟隨構造，羽、毛、皮、金屬與能量效果各自保有可辨的光澤。

## 3. 全身與輸出驗收

1. **全身靜態。** 每個型態至少 8 個水平方位 × 8 個俯仰角，組成至少 64 個不同視角。前後比較使用相同的模型朝向、姿態、鏡頭、取景與中性燈光。檢查腹底、背部、遮蔽處、左右差異、材質交界與家族各型態的輪廓辨識。必要時加拍接觸點與小部位。
2. **代表動作。** 播放最終匯出的相關片段，依物種選擇步態、飛行／游動、收展等，取樣接觸、換腳、伸展及循環首尾。使用既有載入器檢查輪廓、關節、接地、表面分離、穿插與遮蔽。必要時以骨骼或蒙皮後的世界座標定位，再看同一畫面確認。遊戲內混合、逐幀穿插和足底滑移按實測範圍記錄。
3. **交付驗證。** 重開可編輯檔，獨立載入最終 GLB，核對資源、索引、關節與權重、片段名稱及預期改動。外觀修復比對原骨架與動畫資料。動作也在範圍內時，記錄有意修改的曲線與片段。改動後重跑受影響的檢查，以檔案版本或雜湊對應證據。交付可編輯來源、匯出物、視角圖、適用的動作圖及修復紀錄，標明實際檢查與待驗項目。

需要相機配置、重建判例或驗收範例時，讀 [御三家案例](references/starter-case.md)。
