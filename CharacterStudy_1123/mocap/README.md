The data used in this project was obtained from mocap.cs.cmu.edu.
The database was created with funding from NSF EIA-0196217.

These BVH files are the cgspeed conversion of Carnegie Mellon Graphics Lab
recordings, distributed in [cmu-mocap](https://github.com/una-dinosauria/cmu-mocap/tree/master/data).
Trial names identify the performer and take in the [CMU catalogue](https://mocap.cs.cmu.edu/).
The Blender Action properties record the trial and the three source rows.
Interaction contacts and finger curls are authored adjustments.
