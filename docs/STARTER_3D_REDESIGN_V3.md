# 御三家 V3：由生物原型重設三維外觀、骨架與運動

日期：2026-11-11。最新修訂：V3.2，12 型態重建、303 個原訂動作及 93 個補充動作、貼圖與重開驗證。這是可編輯的製作交付修訂；原畫還原與遊戲內表演尚未獲使用者驗收。

## V3.2 自然外觀修訂

本輪按使用者要求繼續精修，而非以「可開啟」代替美術品質：狼眼降低凸出、收窄成年眼形，調整口鼻與耳廓；頰毛向外後方生長，胸毛分成較大主束與細束，尾骨改上捲並加分束毛。毛羽按部位的生長方向與輪廓需求安排，疏密、長短、寬窄和曲率有主次；避免等距整排，也避免無方向的亂刺。脅腹保留平順短毛面，較長毛集中在頭頸、肩、臀及尾緣。

日線補足胸腹、背部及頭冠的羽層；飛羽、覆羽有不同長度與輕微彎曲，並保留實際翼骨與羽骨。金飾以主胸飾、鏡片包邊、少量端飾和葉花群組呈現，鏡環與轉軸仍維持機構所需的對稱。星線鬃毛改用較大的導向捲束與次級細束，避免整齊窗簾。色票按 sRGB 轉線性寫入；毛皮高粗糙度，避免白色 sheen 擴充在 GLB 重匯後過度發亮。

毛羽根部從下方身體蒙皮區域取權重；翼羽與鏡飾跟隨實際骨鏈。303 個原訂動作與 93 個診斷片段全部保留，輸出後重新檢查。正側背、收展翼及動作檢閱使用本輪實際模型，舊圖不混用。這是原畫導向的程序雕形修訂，最終表情、細毛與目標引擎驗收仍未獲使用者認可。

## 問題與修正依據

使用者指出 V2 僅正面可看、其他角度形狀異常。重新檢視程式與實際三視圖後，確認這是結構問題：眼睛朝向幾乎固定為正前方；同族共用近似球形頭骨；毛束與翼片多按正面 XY/XZ 排列；背面靠增加相同裝飾補洞。犬科與馬科共用肢體比例及兩段腿運動，沒有各自的肩胛、腕、膝、跗關節與長掌／蹠骨關係。原本重開檔案、權重及動作數檢查只能證明技術可讀，不能證明造型或動畫成立。V2 的美術合格結論撤回。

本輪依現有三份 concept.json 的原型與立繪重新設計。保留角色身分、色系、進化要素與技能意圖；用解剖與機構推導立繪未清楚交代的深度。下述比例、關節控制範圍及奇幻器官均是本專案的設計選擇，不是實測生物數據。

## 外觀與材質規則

先建裸體積，再檢查灰模，最後增添毛羽／機構。頭、胸廓、骨盆、四肢、尾根必須從所有角度連續；側面可辨眼窩、鼻梁、下顎與頸胸接合。眼球在眼窩內，犬科略向前、馬科偏側、鷺鳥位於長頭兩側；不把兩片正面眼貼搬到所有物種。左右側均建立眼球、耳腔及下顎。

羽毛採表面法線、羽流方向與翼骨局部座標。翼背／翼腹的覆羽不同；折翼保留三段 Z 字骨架與疊羽關係。狼毛先以整體毛皮包覆體積，僅在頰、頸、胸、肘、臀與尾尖用少量簇束改剪影；細毛交由材質，不能反覆堆厚片。馬鬃沿頸背連續，不做左右對稱窗簾；馬尾有細尾骨與連續毛束。

皮毛粗糙；眼球濕潤；喙／爪／蹄為角質；金屬框與鏡面分材質；極光、星點、電弧用獨立可關閉效果。灰模階段不用強發光、描邊或大毛量遮掩結構。V3 基線使用簡化色塊；V3.1 已加入封裝的 base_color、normal、ORM 三張圖集及材質分區。毛羽微紋理為本專案程序繪製，不是高模烘焙；鏡面在 GLB 中仍受檢視器的環境光影響。

## 骨架與控制

共同：Root 地面定位 → Pelvis／軀幹 → Lumbar／Thorax → Neck 鏈 → Head；獨立 Jaw、雙眼、左右耳（適用時）、3–5 段尾骨。脊柱與頸在結構原型先用少量有意義的關節；正式軟體積蒙皮再增補 twist／volume 骨。骨長固定，不以拉長骨頭追腳。

| 系統 | 變形鏈 | 控制與檢查 |
|---|---|---|
| 鷺腿 | Hip → knee（藏於軀幹）→ hock → tarsometatarsus → toe fan | 不能把可見向後的跗關節誤認為膝；單足支撐先移重心，三前一後趾貼地 |
| 鳥翼 | Shoulder → elbow → wrist → hand／羽扇 | 肘腕折疊；初級羽跟手部、次級羽跟前臂；鏡羽獨立調角，不跟著胸廓亂轉 |
| 犬前腿 | scapula → humerus → forearm → carpus → metacarpus → paw | 肩胛滑動、肘向後、腕與趾有緩衝；四爪不互相串權重 |
| 犬後腿 | pelvis → femur／stifle → tibia／hock → metatarsus → paw | 膝朝前、跗朝後；轉身用落足再轉重心，尾巴反向平衡 |
| 馬前腿 | scapula → humerus → forearm／carpus → cannon → fetlock → hoof | 分清腕、球節、蹄；觸地蹄面平穩，離地再收蹄 |
| 馬後腿 | pelvis → thigh／stifle → gaskin／hock → cannon → fetlock → hoof | 膝與跗協同、後軀推蹬；不能照搬狼的彎腿幅度 |
| 天馬翼 | FantasyWingGirdle → humerus → radius/ulna → hand | 這是額外的奇幻翼帶，與四條馬腿獨立；主體胸背承接翼根，不從細馬頸伸出 |
| 鏡陣 | back mount → gimbal axes → mirror pivot／array rings | 軸心與幾何位置一致；背羽、翼、環的運動範圍不互相穿過 |

正式蒙皮必須分區：身體軸、頭頸、各自肢體、尾與翼，僅在相鄰關節混合。取消整隻模型的無分區最近骨距離權重，避免腹部被抬腿拉扯、左腿吸到右腿。
