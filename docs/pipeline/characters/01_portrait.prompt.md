角色設計 Prompt 與生成規則：
- 成人女性於角色識別與正面圖 Prompt 記載同一個隨機選定的 A–E Cup；未成年角色維持非性化描述。
- 先生成正面圖；三視圖與主立繪的 Prompt 開頭均須寫「參照第一張生成的正面圖」，並實際使用該圖作為參考，維持外觀一致。
- 正面圖與三視圖的 Prompt 正文均須明寫以下規則。必須採用嚴格 T-pose：軀幹直立，雙臂在肩高向左右水平伸直，與軀幹各成 90°，雙肘伸直、手腕平直、掌心朝下、手指自然伸直，雙腿伸直、雙腳略分平行、腳尖朝前，重心均分。禁止 A-pose、垂臂、斜抬手臂、屈肘、彎腕、叉腰或動態站姿。道具固定於服裝、腰間或背部，雙手保持空手。
- 三視圖須明寫各視角的姿勢要求。正面、正側面、背面及 3/4 視角均須鎖定同一全身姿勢，只改變正交相機的觀察方位。每格須完整呈現角色，側面依投影自然呈現手臂的縮短與重疊。
- 三視圖嚴格禁止文字、標籤、字母、數字、標誌與浮水印。
- 主立繪描繪符合角色文化、背景與職業的具體場景，使用完整不透明背景。一張完整直式的主角前景與背景立繪圖，畫面連續完整，不要分割成多圖、分格或拼貼。
- 三種圖的 Prompt 標題分別標示 `{{subject_id}}_01_portrait_front.png`、`{{subject_id}}_01_portrait_turnaround.png`、`{{subject_id}}_01_portrait_main.png`；有版本時依命名規範加在圖類型前。
